## Premise (THESIS §3.1)

You cannot dig the poison out. You establish conditions under which the landscape processes it — hydrologic isolation, plants that take it up, wet ground where it breaks down, time — then run time and find out.

| Loop beat | Contaminant expression |
|---|---|
| Build the form | Berms / hollows / substrate choice route or hold load |
| Choose the forces | Rain / season / erosion intensity change flushing vs concentration |
| Run time | Decadal uptake / sequestration / decay |
| Life moves in | Arrival gate opens only when load falls (**C-007**) |
| Persistence | It counts when the place keeps recovering after you stop (G-005) |

## First slice shape (when tip reaches implement)

One substance field on the soil column that:

1. **Transports with water** under the existing mass balance — total substance conserved across cells; no second ledger (H-004).
2. **Decays / sequesters** on a vegetation-mediated pathway in the decadal band.
3. **Survives save** as legacy (T-003 / SIMULATION_MODEL §12) — dropping it invalidates the save.
4. **Gates arrival** — nothing establishes above a threshold; something does below (**C-007**); probe mirrors `arrival-earned` / `salinity-arrival`.
5. **Reads in the place** — encoding so an unfamiliar viewer can name the historical load as the block (S-008) — not an inspector-only ppm readout.

Scenario fixture: one authored contaminated hollow (or ridge deposit) under sandbox forces — not a cleanup wand.

## Hard bans

- A **cleanup tool** applied to a cell (N-001, D-001).
- A **second water / substance mass balance** that does not ride precip → infil → runoff → ocean (H-004).
- A **raw score** or win meter on contaminant ppm (N-002) — objectives read through arrival and persistence.
- Treating **C-018 salinity** as the toxic-site closeout — salt is the everyday instance; contaminant remains distinct.
- Inventing Locked decay kinetics from thin air — cite a real-world referent (N-004 / C-011) or keep Open.
