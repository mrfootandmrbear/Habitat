## Why this document exists

The owner kit-out a sand-castle craft toolbox (2026-08-02): buckets and molds, heavy shovel, watering can, trowels, carving needles, rake, blow straw, beachcomber stash, flags, miniature props, duplicator stamp, smoothing sponge, freeze/dry spray.

That kit is the right *metaphor* for phase-one sculpting (THESIS §2 — you are a person with a bucket). It is not a literal feature list. Habitat's sand is **every substrate nature has to work with**, not granular falling-sand (THESIS §2.1–§2.2). This document reconciles each tool against Locked decisions so the terrain-tools wave after §4.54 does not invent wet-sand physics, freeze-against-the-tide, or placeable life.

This is not a Lock. It does not weaken any cited entry. Structural form tools implement under **C-006** as hypotheses; chrome and freeze do not.

## The contract that filters the kit

| Already Locked | What it does to the kit |
|---|---|
| **C-006** | Sculpting is unrationed — size tiers, molds, flatten, copy-stamp may multiply *verbs*, never an edit budget |
| **A-005** | Every tool sites a **cause** (form / material / ignition intent) — never a finished wetland, meadow, or peasant village |
| **C-009** | **Deposit** already is the geological "bucket of sand/clay/rock"; berm/dig stay shape-only |
| **C-013** | Accidental slips are **undo** before time advances — not a freeze spray |
| **C-004** | After the build, the verb is force regimes — rain, wind, tide, erosion intensity — not cell-targeted magic |
| **THESIS §2.2** | No invented materials or forces; everyday intuition is the instrument; **not** a falling-sand rule set |
| **N-001** / **C-007** | Life arrives when conditions suit — never placed as shells-that-are-critters or sand-peasant figurines |
| **C-022** | Erosion *intensity* is a force dial — must not become a "smooth this hill" nature brush; a **player** flatten/smooth *edit* is still sculpting (C-006), distinct from dialling weather |

## Kit map — keep / reframe / ban

### 1. Structural & foundation

| Owner name | Habitat mapping | Verdict |
|---|---|---|
| **Trusty Bucket Set** (basic buckets) | Brush **size** tier — small continuous berm/dig/deposit footprint | **Keep** — ships §4.55 under C-006 |
| **Geometric molds** (pyramid, star fort, cylinder) | One-shot **form stamps** that raise/lower elevation(+depth) in a fixed footprint — still a terrain cause | **Keep (later slice)** — under C-006 / A-005; not Townscaper building paint |
| **Heavy Shovel** | Brush **size** tier — large footprint / deeper stroke for mass berms and trenches | **Keep** — ships §4.55 with the bucket |
| **Watering Can / Sprayer** ("wet sand" carveability) | **Ban as wet-sand physics.** Moisture already exists as hydrology; rain is a **Force** dial (C-004 / C-020). Inventing a sculpt-mode where sprayed water changes how sand *carves* is falling-sand (THESIS §2.2). Reframe: the watering can *is* the rain regime — you wet the castle by choosing forces and running time | **Ban / reframe to Force rain** |

## First slice shape (§4.55 — under Locked C-006)

No new `Process`. No Open gate to start.

1. **Brush size dial** — `bucket` (current radius) and `shovel` (larger radius) shared by berm / dig / deposit.
2. Cursor footprint tracks the active size.
3. Tier-M: footprint cell count scales with size; ΣΔelev = ΣΔdepth still holds (C-002); 100 edits still write no veg (C-006).
4. Labels stay cause-shaped: "Brush: bucket" / "Brush: shovel" — craft names, not spell names.

**Next-but-one after §4.55:** flatten/trowel edit (§4.56 stub), then mold stamps + duplicator — still form-only, still no veg copy.

## Hard bans (agents)

- Wet-sand **sculpt physics** or a moisture dial that changes how berm/dig carve (THESIS §2.2).
- **Freeze / lock / protect** cells against tide, waves, erosion, or fire.
- **Place life** — figurines, seaweed-as-biota, shell critters, banners that spawn occupancy (N-001, C-007).
- Copy-stamping **vegetation, water, or suitability** as a finished habitat.
- An edit **budget**, cooldown, or ration on any sculpt tool (C-006).
- Treating the **erosion force dial** as the smoothing sponge (C-022).
