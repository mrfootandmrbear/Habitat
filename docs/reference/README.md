# Reference images — the Gauntlet Loop bar

Drop reference screenshots here. Any common image format is fine; name them
for what they're meant to demonstrate, e.g.:

    terrain-material.png
    water-shoreline.jpg
    sky-atmosphere.png
    vegetation-density.png

## Why this folder exists

The gauntlet-loop skill ranks the bar a critic scores against, strongest first:

1. **Real reference artifacts** — a critic can do a genuine blind side-by-side.
2. **A written rubric** — the fallback when no reference is available.

Habitat has been running on option 2 (the 12 checkable points in
`docs/VISUAL_UPGRADE_NOTE.md`) because outbound web access was blocked when
the loop started, so no reference art could be fetched. The rubric does work
— it caught real defects — but critics grade against prose, and the wording
becomes the ceiling on what they can ask for.

Images placed here replace that with the stronger bar. One image per thing
you care about beats a large unsorted pile: each piece's critic is shown only
the references relevant to that piece.

A short note on *why* you picked an image ("the way wet sand darkens at the
waterline", "this cloud shading") is worth more than the image alone — it
tells a critic what to look at instead of leaving it to guess.
